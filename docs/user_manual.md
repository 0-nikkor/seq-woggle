# User Manual — Seq / Woggle V4.8

## 1 · Quick Start

Power on via USB-C power bank. The LCD shows the current mode.  
Rotate the encoder to change values. Press to move to the next parameter.  
All settings are saved automatically 1.5 seconds after your last edit.

### Controls

| Action | Result |
|--------|--------|
| Rotate encoder | Change current parameter value |
| Short press | Move to next parameter (wraps back to PROGRAM) |
| Long press 900ms | In Woggle PRESET only: load the highlighted preset |

### Switching modes

Navigate to **PROGRAM** (first parameter in the cycle), then rotate to switch between **Seq** and **Woggle**.

## 2 · Outputs

| Output | Voltage | Description |
|--------|---------|-------------|
| CV | 0–3.3V | Quantized pitch or modulation voltage |
| CLOCK | 0 / 3.3V | Main gate / clock pulse |
| BURST | 0 / 3.3V | Euclidean gate (Seq) or random burst (Woggle) |

---

## 3 · PWM FREQ — Precision vs Expressivity

The CV output is generated by PWM filtered through a 1kΩ + 100nF RC network.  
**PWM FREQ** controls the carrier frequency:

- **High (10–20 kHz)** → minimal ripple → stable, precise CV → ideal for pitch
- **Low (500 Hz – 3 kHz)** → more ripple → micro-movement, grain, analogue texture → expressive for filters, waveshapers, VCAs

---

## 4 · Seq Mode

At each step: CV updates, CLOCK fires, BURST fires if the Euclidean pattern hits.

### Key concepts

- **Quantization**: notes are always forced to the selected scale — random but musical
- **Lock buffer**: turns random notes into a repeatable phrase. LOCK PROB controls how fast it evolves
- **Euclidean BURST**: second rhythmic layer on BURST jack — ideal for envelope triggers, ratchets
- **Swing + Jitter**: swing gives groove structure, jitter gives human imperfection
- **Mute**: removes gate pulses, not CV — pitch still evolves through silent beats
- **EUC ROT**: shifts the Euclidean pattern phase without changing density — excellent live performance gesture

### Parameters

See [`docs/parameters.md`](parameters.md) for full parameter reference.

### Recipes

| Goal | Settings |
|------|----------|
| Evolving melodic phrase | LOCK LEN 8–16, LOCK PROB 10–20%, JITTER low |
| Turing machine style | LOCK LEN 8–32, LOCK PROB 5% |
| Chaotic generator | LOCK LEN 0, RANGE wide, SCALE Chromatic |
| Rhythmic layering | EUC HITS set, rotate EUC ROT live |
| Analogue feel | Lower PWM FREQ for CV ripple texture |

## 5 · Woggle Mode

Generates a continuously evolving CV from three layers:

| Layer | Character | Controlled by |
|-------|-----------|---------------|
| Stepped | Sample-and-hold jumps | RATE, CHAOS |
| Smooth | Lagged/interpolated curve | LAG, CHAOS |
| Woggle | Mix of both + edge noise | MIX, CHAOS |

BURST OUT fires random burst pulses according to B.PROB, B.MIN, B.MAX, B.SPRD.

### Recipes

| Goal | Settings |
|------|----------|
| Soft slow modulation | RATE slow, CHAOS low, LAG high, MIX high |
| Classic S&H | MIX low, LAG low, RATE medium |
| Rhythmic ratchet | B.PROB high, B.MIN 2–4, B.MAX 6–10, PULSE short |
| Expressive filter | Lower PWM, LAG and MIX as main gesture controls |

---

## 6 · Tips

- CV is 3.3V. Use an attenuverter or offset module if your VCO needs a wider range.
- Gate outputs are 3.3V. Add a level shifter if your module requires 5V.
- EUC ROT is the most powerful live parameter in Seq — keep HITS fixed and rotate live.
- TUNE calibrates V/oct to your specific RC filter and receiving module.
- Power-off within 1.5s of a change may not save the last edit.
