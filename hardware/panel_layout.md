# Panel / Enclosure Layout

## Suggested front panel (top face of box)

```
    ┌─────────────────────────────────────────────┐
    │  [CV]   [CLOCK]  [BURST]    (Enc)           │
    │   ○        ○        ○       (knob)           │
    │                                              │
    │         ┌──────────────────┐                 │
    │         │  Seq:TEMPO       │  ← LCD 16×2     │
    │         │  240ms           │                 │
    │         └──────────────────┘                 │
    └─────────────────────────────────────────────┘
```

## Hole sizes

| Component | Hole size |
|-----------|-----------|
| 3.5mm jack PJ301M | Ø 6mm (or 1/4" = 6.35mm) |
| Encoder shaft KY-040 | Ø 7mm |
| LCD window | ~72×24mm rectangular cutout (or 3mm mounting holes) |

## Recommended enclosure size

Minimum: **12 × 8 × 4 cm**  
Comfortable: **14 × 10 × 5 cm**

## Jack spacing

At least **18mm centre-to-centre** between jacks for comfortable patching with standard patch cables.

## Labelling

Print a paper faceplate, laminate it, and glue to the front panel before mounting jacks and encoder.  
Or use a label maker / Dymo tape directly on the box.

Suggested labels: **CV · CLK · BST** (or **CV · CLOCK · BURST**)
